**Stack:**
- Frontend: Vite, React, Typescript.
- Backend: Python FastAPI
- Discord Bot: Python
- Database: PostgreSQL
- ORM: SQLAlchemy
- Deployment: Vercel (Frontend), Railway (Backend), Wispbyte (Discord Bot), Supabase (Database)
